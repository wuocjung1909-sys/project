About Me & Design Approach

I am a software engineering student focused on building clean, maintainable, and accessible front-end interfaces using semantic HTML5 and standards-compliant CSS3.

This portfolio was built following a mobile-first workflow: starting from low-fidelity wireframes, establishing consistent spacing and typography, and scaling smoothly across mobile, tablet, and desktop viewports.

Core Technical Highlights

01. Standards

W3C Valid HTML5 & CSS3

Proper landmark elements, alt attributes on all images, and clean stylesheet syntax.

02. Responsiveness

Fluid Breakpoints

Adapts seamlessly from single-column mobile views to 2-column and 3-column desktop grids.

03. Polish

Interactive States

Smooth hover transitions, sticky header navigation, and custom web fonts.
